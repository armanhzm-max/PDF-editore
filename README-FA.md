# گزارش اصلاح خطای Build

## تغییر این نسخه

در فایل `worker/index.ts` خطای TypeScript مربوط به آرایه پیام‌های AI اصلاح شد.

- پیام جدید کاربر ابتدا با نوع صریح `AIMessage` تعریف می‌شود.
- سپس همان پیام به تاریخچه اضافه می‌شود.
- این کار مانع تعمیم نوع `role` به `string` می‌شود و نوع محدود `"user" | "assistant"` را حفظ می‌کند.

اصلاحات قبلی نیز حفظ شده‌اند:
- اضافه‌شدن مترجم به نوار اصلی در `src/ui/App.tsx`.
- حذف شرط تکراری `quote` از مسیر پیش‌فرض خروجی PowerPoint در `src/ui/PowerPointWorkspace.tsx`.

## نصب

1. از پوشه فعلی پروژه نسخه پشتیبان بگیرید.
2. ZIP را استخراج کنید.
3. پوشه `pdf-ai-tools` داخل ZIP را جایگزین پوشه فعلی پروژه کنید، یا فقط فایل‌های داخل آن را با حفظ ساختار پوشه‌ها روی پروژه فعلی کپی کنید.
4. در PowerShell از ریشه پروژه اجرا کنید:

```powershell
npm install
npm run build
```

5. فقط پس از موفقیت Build اجرا کنید:

```powershell
npm run preview
```

## وضعیت اعتبارسنجی

این اصلاح از نظر ساختار TypeScript بررسی ایستا شده است. Build کامل وابسته به نصب وابستگی‌ها و باید در محیط پروژه اجرا و تأیید شود.

## ✨ Overview

PDF & Image AI Tools is a bilingual (English/Persian) web application that brings common document and file workflows into one interface. It combines browser-local PDF and image utilities with dedicated workspaces for scanned documents, text documents, spreadsheets, presentations, and document collections.

The project follows a **local-first approach for document processing**: supported files are processed in the browser, and the original documents are not routinely uploaded to the application Worker. Account, subscription, payment, and feedback operations use the backend where required.

> **Important current-release status:** General AI features (AI Documents, Assistant, and Agent) are intentionally disabled by default. The application includes preparation and integration infrastructure, but this release must not be presented as having active AI analysis or chat. Translation is a separate, opt-in feature and is also disabled unless explicitly configured by the operator.

## 🧰 What you can do

### 📑 PDF tools

- **PDF Editor:** preview PDFs, reorder pages, rotate or delete pages, extract pages, add text-note overlays, draw a signature, and work with basic AcroForm text and checkbox fields.
- **Merge PDFs:** combine supported PDF files.
- **Split PDFs:** separate a PDF into selected page ranges.
- **Compress PDFs:** reduce PDF file size using the available browser-side processing.
- **Extract text:** extract selectable text from supported PDFs.
- **PDF OCR:** recognize text from PDFs and export the recognized text.

PDF editor notes:
- Text notes are raster overlays, not editable PDF text objects.
- AcroForm appearance regeneration uses Helvetica. Carefully inspect Persian form-field output before commercial use.
- The hidden searchable layer generated by the current OCR export supports ASCII/English words; Persian OCR text remains available in TXT output.

### 🖨️ Scan Center

The Scan Center turns images and scanned PDFs into editable, reusable outputs.

- Accepts JPG, PNG, WEBP, and scanned PDF input.
- Renders PDF pages locally to images.
- Reorders, removes, and rotates pages.
- Offers original color, grayscale/contrast, and black-and-white processing modes.
- OCR languages: Persian (`fas`), English (`eng`), or both (`fas+eng`).
- Lets the user draw a region of interest for OCR. The same normalized region can be applied across pages, or page-specific regions can be selected.
- Allows recognized text to be corrected page by page.
- Exports a scan-oriented multi-page PDF and, after OCR, editable DOCX and UTF-8 TXT.

Current Scan Center limits: 20 pages, 50 MB per image, 100 MB combined, 32 megapixels per image, and 80 megapixels combined. Automatic page-edge detection, perspective correction, manual crop handles, handwriting OCR, and HEIC/HEIF are not included in this phase.

### 🗂️ Office workspaces

| Workspace | Supported capabilities | Important limitations |
|---|---|---|
| **Word** | Open DOCX and UTF-8 TXT; edit common paragraphs, headings, basic inline formatting, lists and simple tables; export editable DOCX | Not a full Microsoft Word replacement. Images, charts, SmartArt, embedded objects, headers/footers, notes, tracked changes, comments, and complex layout are not preserved. |
| **Excel** | Open XLSX, CSV and TSV; edit cells; formula bar; search; AutoSum; supported formulas; sort; row/column operations; undo/redo; export XLSX/CSV | Imports the first worksheet and exports one worksheet. No macros, charts, advanced formatting, multi-sheet preservation, or full Excel formula compatibility. |
| **PowerPoint** | Create simple presentations; import PPTX text; add, duplicate, delete, reorder slides; edit title/body; choose from six solid backgrounds; export editable PPTX or text outline | Import does not preserve images, charts, animations, SmartArt, speaker notes, embedded media, or complex formatting. |
| **My Workspace** | Autosave supported drafts locally; search and filter drafts; open/delete drafts; JSON backup export/import; optional selected-folder integration | Local browser storage and JSON backups are not separately encrypted by this app. |

Additional details:

- Word supports common DOCX structures and basic Persian/Arabic right-to-left paragraph direction. Pasting is plain text.
- Word's A4 page preview is an approximate on-screen preview; actual PDF page breaks are performed by the browser print engine.
- Word PDF output uses **Print → Save as PDF**, not a direct PDF export.
- Excel supports arithmetic and `SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`, `COUNTA`, and `PRODUCT`, with circular-reference detection. It is not a complete spreadsheet calculation engine.
- PowerPoint supports up to 60 slides under the current import limits.

### 🧠 Document Intelligence and connected workflows

The Document Intelligence workspace can locally extract text from up to 10 files per task (PDF, DOCX, XLSX, PPTX, TXT, CSV, TSV; 20 MB each and 60 MB combined). Its interface and workflow scaffolding support tasks such as summarizing, comparing, asking questions, structured extraction, translation, and presentation-outline preparation.

**However, AI model access is disabled in this release.** The UI must report the feature as unavailable while the Worker reports AI disabled. No document text, prompt, image, or tool result should be sent to an AI provider in this state.

Short-lived in-memory handoffs connect workspaces:
- Scan Center OCR text → Word, Document Intelligence, or Translator.
- Word content → Document Intelligence.
- Document Intelligence output → Word.

These handoffs remain in application memory and are cleared after the receiving workspace consumes them. They are not automatically uploaded.

### 🌐 Translator

Translation is an independent opt-in capability, separate from general AI.

- Uses an authenticated Worker endpoint.
- Sends only the exact text entered by the user after consent; it does not send the original document or image.
- Current documented daily limits: Free — 3 requests/day and 3,000 Unicode code points/request; Pro — 200 requests/day and 20,000 code points/request.
- Requires explicit operator configuration of the provider endpoint, model, secret, database migration (for existing databases), and `TRANSLATION_ENABLED=true`.

Do not enable translation until provider terms and the application's privacy notice have been reviewed.

### 👤 Accounts, plans, billing, and feedback

- Account creation and sign-in use passwordless, single-use email verification codes. No password is stored by this authentication flow.
- Codes expire after 10 minutes.
- The Worker supports subscription and payment operations, including Stripe and Zarinpal integration.
- Stripe Customer Portal can be configured for subscription management.
- The bilingual feedback page accepts ratings, bug reports, feature requests, usability notes, and general comments. Users should not submit document contents in feedback.
- Feedback exports are protected by a server-side `FEEDBACK_ADMIN_TOKEN`.

These backend capabilities require a correctly configured and deployed Worker and database. Merely running the frontend locally does not activate hosted authentication, payments, or feedback administration.

## 🔒 Privacy and file handling

The application is designed to keep supported document processing in the browser:

- PDF, image, Office-file parsing, OCR, and local workspace operations run client-side where documented.
- Original documents are not stored in the D1 account database.
- The selected device folder is accessed only after the user explicitly chooses and grants access to it in a supported browser.
- Folder handles and document contents are not sent to the Worker.
- Account details, subscription/payment records, and feedback deliberately submitted by users are handled server-side.
- The application does not encrypt local browser drafts or JSON backup files separately. Protect the operating-system account and browser profile, especially on shared devices.

Browser-side limits improve stability, but they are not a tamper-proof security boundary for paid entitlements. Do not treat UI-only limits as server-enforced authorization.

## ☁️ Configuration and deployment

The backend uses `wrangler.toml`, Cloudflare Worker secrets, D1, and KV. Deployment is not a one-command setup: create the required Cloudflare resources, configure the IDs/bindings in `wrangler.toml`, apply the correct schema/migrations, set secrets, configure external providers, and then deploy.

### Cloudflare resources

Create a KV namespace and a D1 database if they do not already exist:

```bash
npx wrangler kv namespace create KV
npx wrangler d1 create pdf-ai
```

Update the IDs and database binding in `wrangler.toml` with the values returned by Wrangler.

For a **new database**, apply the current schema:

```bash
npx wrangler d1 execute pdf-ai --file=worker/schema.sql --remote
```

For an existing database, inspect its migration history first and apply only the migrations it needs. Do not blindly rerun historical migrations. Relevant migration files include:

- `worker/migrations/0002_stripe_subscription.sql`
- `worker/migrations/0003_feedback.sql`
- `worker/migrations/0004_translation_usage.sql`
- `worker/migrations/0005_security_hardening.sql`
- `worker/migrations/0006_auth_challenges.sql`

The exact sequence depends on the database's starting schema. Back up production data and test migrations in a development database before applying them to production.

### Worker secrets

Set secrets using Wrangler; never commit real secret values:

```bash
npx wrangler secret put JWT_SECRET
npx wrangler secret put RESEND_API_KEY
npx wrangler secret put STRIPE_SECRET_KEY
npx wrangler secret put STRIPE_WEBHOOK_SECRET
npx wrangler secret put ZARINPAL_MERCHANT_ID
npx wrangler secret put FEEDBACK_ADMIN_TOKEN
```

Important:
- `JWT_SECRET` must contain at least 32 characters.
- `FEEDBACK_ADMIN_TOKEN` must be a random secret of at least 32 characters.
- Configure and verify the Resend sender domain and `MAIL_FROM`.
- Configure Stripe webhook delivery for the deployed application URL. The documented route is `/api/billing/stripe/webhook`.
- Zarinpal uses `/api/billing/zarinpal/callback`.
- Configure Stripe Customer Portal in the Stripe dashboard if subscription self-service is required.
- Never put provider keys in frontend variables, source files, or public repository commits.

### AI and translation activation policy

Keep these defaults disabled unless the project owner explicitly approves a reviewed activation:

- `AI_ENABLED = "false"`
- `AGENT_ENABLED = "false"`
- `TRANSLATION_ENABLED = "false"`

General AI requires provider selection, secret configuration, privacy disclosures, cost limits, quotas, and a staged rollout. The Translator has a separate flag and quota system; enabling it must not enable general AI. Follow `Documentation/AI/API-INTEGRATION-GUIDE.md` and the translation instructions in this README before making changes.

## 🧩 Adding a tool

The tool registry discovers modules under `src/tools/*/index.ts`.

1. Create a tool folder, for example `src/tools/my-tool/`.
2. Add `index.ts` and export a default object that conforms to the `Tool` type in `src/core/types.ts`.
3. Define the tool's accepted file types, whether it accepts multiple files, any options, and its `run` implementation.
4. Add or update tests for validation, file limits, output behavior, and security.
5. Run the relevant focused checks, then `npm test` and `npm run build`.

Do not add arbitrary AI or network behavior to a local tool. Keep file handling explicit, bounded, and consistent with the validation and permission layers.

## ⚠️ Known limitations

This project is an actively developed document utility suite, not a complete replacement for Microsoft Office or a fully activated AI platform. In particular:

- General AI chat, AI document analysis, and agent tool execution are disabled in the current release.
- Translation is disabled unless separately configured and approved.
- Persian searchable text in generated PDF OCR layers is not currently supported by the bundled standard font; Persian text is available in TXT/DOCX outputs where specified.
- OCR quality depends on scan quality and language data. Handwriting recognition is not included.
- Some advanced Word, Excel, and PowerPoint structures are simplified or not preserved; review exported files in a full Office suite before relying on them.
- Browser storage, folder permissions, and File System Access API support vary by browser and device.
- The application requires internet access for account, Worker API, AI/translation (when enabled), and payment features. Local file tools can work in the browser without uploading the source file.

# نسخه فارسی

## ✨ معرفی

**PDF & Image AI Tools** یک برنامه وب دوزبانه (فارسی و انگلیسی) برای انجام کارهای رایج PDF، تصویر و اسناد اداری در یک محیط یکپارچه است. این برنامه ابزارهای PDF و تصویر، مرکز اسکن و OCR، محیط‌های کاری Word و Excel و PowerPoint، فضای ذخیره‌سازی محلی اسناد و گردش‌کارهای بین این بخش‌ها را ارائه می‌کند.

رویکرد اصلی برنامه **پردازش محلی در مرورگر (Local-first)** است: فایل‌های پشتیبانی‌شده تا جای ممکن در مرورگر کاربر پردازش می‌شوند و فایل اصلی به‌طور معمول به Worker آپلود نمی‌شود. عملیات حساب کاربری، اشتراک، پرداخت و بازخورد در بخش سرور انجام می‌شوند.

> **وضعیت مهم نسخه فعلی:** قابلیت‌های عمومی هوش مصنوعی شامل تحلیل هوشمند اسناد، دستیار و اجرای Agent عمداً غیرفعال هستند. زیرساخت آن‌ها در پروژه وجود دارد، اما در این نسخه نباید برنامه را دارای چت یا تحلیل فعال هوش مصنوعی معرفی کرد. مترجم قابلیت جداگانه‌ای است و آن هم تا زمان پیکربندی و فعال‌سازی صریح مدیر غیرفعال می‌ماند.

## امکانات اصلی

### 📑 ابزارهای PDF و تصویر

- ویرایش PDF: پیش‌نمایش، جابه‌جایی صفحات، چرخاندن، حذف و استخراج صفحات.
- افزودن یادداشت متنی به‌صورت لایه تصویری و رسم امضا.
- پشتیبانی پایه از فیلدهای متنی و چک‌باکس AcroForm.
- ادغام چند PDF، تقسیم PDF، فشرده‌سازی PDF و استخراج متن.
- تبدیل تصاویر به PDF و تبدیل فرمت تصویر.
- OCR برای استخراج متن از PDFهای پشتیبانی‌شده.

**محدودیت‌های مهم:** یادداشت‌های متنی به متن قابل‌ویرایش PDF تبدیل نمی‌شوند. لایه جست‌وجوی مخفی OCR در PDF فعلاً برای واژه‌های ASCII/انگلیسی است؛ متن فارسی در خروجی TXT حفظ می‌شود. ظاهر فیلدهای فارسی AcroForm را پیش از استفاده تجاری بررسی کنید.

### 🖨️ مرکز اسکن هوشمند

- دریافت تصاویر JPG، PNG و WEBP و PDF اسکن‌شده.
- تبدیل صفحات PDF به تصویر در مرورگر.
- مرتب‌سازی، حذف و چرخاندن صفحات.
- پردازش رنگ اصلی، خاکستری/افزایش کنتراست و سیاه‌وسفید.
- OCR فارسی، انگلیسی یا ترکیبی.
- انتخاب محدوده دلخواه برای OCR با رسم مستطیل.
- اصلاح متن تشخیص‌داده‌شده به‌صورت صفحه‌به‌صفحه.
- خروجی PDF چندصفحه‌ای، DOCX و TXT.

محدودیت فعلی: حداکثر ۲۰ صفحه، ۵۰ مگابایت برای هر تصویر، ۱۰۰ مگابایت مجموع ورودی، ۳۲ مگاپیکسل برای هر تصویر و ۸۰ مگاپیکسل مجموع. تشخیص خودکار لبه صفحه، اصلاح پرسپکتیو، OCR دست‌خط و ورودی HEIC/HEIF در این مرحله وجود ندارد.

### 🗂️ محیط‌های کاری اداری

- **Word:** بازکردن DOCX و TXT، ویرایش ساختارهای متداول متن، تیتر، قالب‌بندی پایه، فهرست و جدول ساده و خروجی DOCX. جایگزین کامل Microsoft Word نیست و برخی اجزای پیشرفته را حفظ نمی‌کند.
- **Excel:** بازکردن XLSX، CSV و TSV، ویرایش سلول‌ها، نوار فرمول، جست‌وجو، AutoSum، تعدادی فرمول پایه، مرتب‌سازی، افزودن/حذف ردیف و ستون، Undo/Redo و خروجی XLSX/CSV. فقط شیت اول را وارد و یک شیت را صادر می‌کند؛ موتور کامل فرمول‌های Excel نیست.
- **PowerPoint:** ساخت ارائه ساده، واردکردن متن PPTX، افزودن/تکثیر/حذف/جابجایی اسلاید، ویرایش عنوان و متن، انتخاب شش رنگ پس‌زمینه و خروجی PPTX قابل‌ویرایش. تصاویر، نمودارها، انیمیشن‌ها و بسیاری از اجزای پیشرفته در واردسازی حفظ نمی‌شوند.
- **فضای کاری من:** ذخیره خودکار پیش‌نویس‌ها در فضای محلی مرورگر، جست‌وجو و فیلتر، بازکردن و حذف پیش‌نویس، پشتیبان‌گیری JSON و اتصال اختیاری پوشه انتخابی کاربر در مرورگرهای پشتیبانی‌شده.

فایل‌های محلی و پیش‌نویس‌ها به‌صورت جداگانه توسط برنامه رمزگذاری نمی‌شوند؛ در دستگاه مشترک از حساب سیستم‌عامل و پروفایل مرورگر محافظت‌شده استفاده کنید.

### 🧠 هوشمندی اسناد و گردش‌کارها

بخش Document Intelligence زیرساخت استخراج متن از PDF، DOCX، XLSX، PPTX، TXT، CSV و TSV را در مرورگر دارد و رابط کاربری آن برای خلاصه‌سازی، مقایسه، پرسش از اسناد، استخراج داده ساختاریافته، ترجمه و آماده‌سازی طرح ارائه طراحی شده است.

با این حال، **اتصال مدل هوش مصنوعی در نسخه فعلی غیرفعال است** و تا وقتی Worker قابلیت را فعال اعلام نکند، نباید هیچ متن، فایل یا درخواستی به ارائه‌دهنده هوش مصنوعی ارسال شود.

انتقال موقت متن بین بخش‌ها نیز وجود دارد: متن OCR به Word یا Document Intelligence یا Translator، محتوای Word به Document Intelligence و نتیجه تحلیل به Word منتقل می‌شود. این انتقال‌ها در حافظه برنامه انجام می‌شوند و پس از دریافت مصرف می‌شوند.

### 🌐 مترجم، حساب کاربری و پرداخت

مترجم یک قابلیت مستقل و اختیاری است. پس از فعال‌سازی صحیح، فقط متن انتخاب‌شده توسط کاربر و پس از تأیید رضایت ارسال می‌شود؛ فایل یا تصویر اصلی ارسال نمی‌شود. سهمیه مستندشده روزانه برای Free برابر ۳ درخواست با حداکثر ۳۰۰۰ نویسه و برای Pro برابر ۲۰۰ درخواست با حداکثر ۲۰۰۰۰ نویسه در هر درخواست است.

ثبت‌نام و ورود با کد یک‌بارمصرف ایمیلی انجام می‌شود؛ کد ۱۰ دقیقه اعتبار دارد و پس از استفاده قابل استفاده مجدد نیست. برنامه زیرساخت اتصال Stripe و Zarinpal و صفحه بازخورد دوزبانه را نیز دارد. فعال بودن واقعی این قابلیت‌ها به تنظیم و استقرار Worker، پایگاه داده و سرویس‌های خارجی وابسته است.

## 🔒 حریم خصوصی و امنیت

پردازش PDF، تصویر، OCR و فایل‌های اداریِ پشتیبانی‌شده در مرورگر انجام می‌شود. محتوای اسناد در پایگاه داده حساب کاربری ذخیره نمی‌شود. پوشه دستگاه فقط پس از انتخاب صریح کاربر و تأیید دسترسی مرورگر متصل می‌شود. اطلاعات حساب، اشتراک، پرداخت و بازخوردی که کاربر آگاهانه ارسال می‌کند در سمت سرور پردازش می‌شوند.

محدودیت‌های سمت مرورگر برای پایداری و تجربه کاربری هستند و به‌تنهایی مرز امنیتی غیرقابل‌دستکاری برای کنترل اشتراک محسوب نمی‌شوند.

## ⚙️ فناوری‌ها

React 18، TypeScript، Vite، pdf-lib، PDF.js، Tesseract.js، Cloudflare Workers، Cloudflare D1 و KV، Stripe، Zarinpal و Resend.

## ☁️ راه‌اندازی و استقرار

برای توسعه محلی به Node.js و npm نیاز دارید. برای Worker به حساب Cloudflare و Wrangler نیاز است. ایجاد KV و D1، تنظیم شناسه‌ها در `wrangler.toml`، اجرای schema یا migration متناسب با وضعیت پایگاه داده، تنظیم Secretها و پیکربندی سرویس‌های خارجی الزامی است.

مقادیر واقعی Secret را هرگز در Git یا فایل‌های فرانت‌اند قرار ندهید. `JWT_SECRET` و `FEEDBACK_ADMIN_TOKEN` باید حداقل ۳۲ کاراکتر باشند. پیش از اجرای Migration روی دیتابیس اصلی، تاریخچه Migration را بررسی و از داده‌ها پشتیبان تهیه کنید.

پرچم‌های `AI_ENABLED`، `AGENT_ENABLED` و `TRANSLATION_ENABLED` در نسخه فعلی باید غیرفعال بمانند، مگر اینکه فعال‌سازی آن‌ها با بررسی حریم خصوصی، هزینه، سهمیه و تنظیمات سرویس‌دهنده تأیید شده باشد.

## 🏗️ ساختار پروژه

```text
.
├── public/          # فایل‌های ثابت، PWA و هدرهای امنیتی
├── shared/          # قراردادها و محدودیت‌های مشترک
├── src/
│   ├── core/        # اعتبارسنجی، دسترسی فایل، مجوزها و گردش‌کار
│   ├── tools/       # ابزارهای ماژولار PDF و تصویر
│   └── ui/          # رابط کاربری و محیط‌های کاری
├── worker/          # API سمت سرور و schema پایگاه داده
│   └── migrations/  # تغییرات D1
├── tests/           # تست‌های امنیتی، اجرایی و بازگشت
└── Documentation/  # مستندات فنی و امنیتی
```
